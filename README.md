# Elite-events.1

## Configuracion del correo

El envio de correos usa Gmail SMTP. Configura `MAIL_USER` y `MAIL_PASSWORD` en el
archivo local `.env`; `MAIL_PASSWORD` debe ser una contrasena de aplicacion de
Google, no la contrasena habitual de la cuenta. No subas el archivo `.env` a
Git. Puedes usar `.env.example` como referencia.
